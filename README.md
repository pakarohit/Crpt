# crpt ‑ Token Swap UI

A mock frontend Swap interface to showcase token selection and wallet connection (UI only).

## 🚀 Tech Stack
- React.js
- Tailwind CSS

## ✨ Features
- **Token dropdown** (ETH, USDT, BTC, MATIC)
- **Mock wallet connect**
- **Swap button** with dynamic alert showing chosen tokens and amount
- **Dark-themed**, responsive UI

## 🧰 Usage
```bash
npm install
npm start
